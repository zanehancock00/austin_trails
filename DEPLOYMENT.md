# Deployment Guide for Austin Trails Web App

This guide provides several options for deploying your Austin Trails application to the web.

## Quick Deployment Options (Recommended)

### Option 1: Render (Free Tier Available)

Render offers free hosting for web services with automatic deploys from GitHub.

**Steps:**
1. Push your code to GitHub (if not already there)
2. Go to [render.com](https://render.com) and sign up
3. Click "New +" → "Web Service"
4. Connect your GitHub repository
5. Configure:
   - **Name**: austin-trails (or your choice)
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app`
   - **Environment Variables**: Add your Strava credentials
     - `STRAVA_CLIENT_ID`
     - `STRAVA_CLIENT_SECRET`
     - `STRAVA_REFRESH_TOKEN`
6. Click "Create Web Service"

**Additional Setup Needed:**
Add `gunicorn` to requirements.txt:
```bash
echo "gunicorn>=21.0.0" >> requirements.txt
```

**Pros:** Free tier, automatic HTTPS, easy setup, auto-deploys
**Cons:** Free tier may spin down after inactivity (cold starts)

---

### Option 2: Railway (Modern & Fast)

Railway provides modern deployment with excellent developer experience.

**Steps:**
1. Go to [railway.app](https://railway.app)
2. Sign in with GitHub
3. Click "New Project" → "Deploy from GitHub repo"
4. Select your austin_trails repository
5. Railway auto-detects Python and starts deploying
6. Add environment variables in the Railway dashboard:
   - `STRAVA_CLIENT_ID`
   - `STRAVA_CLIENT_SECRET`
   - `STRAVA_REFRESH_TOKEN`
7. Click on the service → "Settings" → "Generate Domain"

**Additional Setup:**
Create a `Procfile` in your project root:
```
web: gunicorn app:app --bind 0.0.0.0:$PORT
```

Add `gunicorn` to requirements.txt.

**Pros:** Very fast, modern UI, generous free tier, automatic HTTPS
**Cons:** Free tier has monthly usage limits

---

### Option 3: PythonAnywhere (Always Free)

Great option for Python web apps with a permanent free tier.

**Steps:**
1. Sign up at [pythonanywhere.com](https://www.pythonanywhere.com)
2. Go to "Web" tab → "Add a new web app"
3. Choose "Manual configuration" → Python 3.10
4. Upload your code using Git:
   ```bash
   cd ~
   git clone <your-repo-url> austin_trails
   ```
5. Set up virtual environment:
   ```bash
   mkvirtualenv --python=/usr/bin/python3.10 austin-env
   pip install -r austin_trails/requirements.txt
   ```
6. Configure WSGI file (in the Web tab):
   ```python
   import sys
   import os

   path = '/home/yourusername/austin_trails'
   if path not in sys.path:
       sys.path.insert(0, path)

   from app import app as application
   ```
7. Set environment variables in the Web tab
8. Reload the web app

**Pros:** Always free, no credit card required, stable
**Cons:** Free tier has limitations (daily API call limits), subdomain only

---

### Option 4: Fly.io (Developer-Friendly)

Modern platform with generous free tier.

**Steps:**
1. Install Fly CLI: `curl -L https://fly.io/install.sh | sh`
2. Sign up: `fly auth signup`
3. In your project directory: `fly launch`
4. Follow the prompts to configure your app
5. Set secrets:
   ```bash
   fly secrets set STRAVA_CLIENT_ID=your_client_id
   fly secrets set STRAVA_CLIENT_SECRET=your_secret
   fly secrets set STRAVA_REFRESH_TOKEN=your_token
   ```
6. Deploy: `fly deploy`

**Additional Setup:**
Create a `fly.toml` file (generated by `fly launch`).

**Pros:** Great performance, modern tooling, automatic HTTPS
**Cons:** Requires CLI, slightly more technical

## Required Environment Variables

All deployment options need these Strava API credentials set as environment variables:

- `STRAVA_CLIENT_ID` - Your Strava application client ID
- `STRAVA_CLIENT_SECRET` - Your Strava application client secret
- `STRAVA_REFRESH_TOKEN` - Your Strava refresh token

You can find these in your `.env` file or Strava API settings.

## Production Preparation Checklist

Before deploying, make these changes:

### 1. Update requirements.txt
Add production server:
```
gunicorn>=21.0.0
```

### 2. Update app.py
Change the last line from:
```python
app.run(debug=True, host='0.0.0.0', port=5000)
```

To:
```python
if __name__ == '__main__':
    # Use PORT env variable for production, default to 5000 for local dev
    port = int(os.environ.get('PORT', 5000))
    app.run(debug=False, host='0.0.0.0', port=port)
```

### 3. Add Production Configuration
Create `gunicorn_config.py`:
```python
import os

bind = f"0.0.0.0:{os.environ.get('PORT', 8000)}"
workers = 2
threads = 4
timeout = 120
```

### 4. Update Strava OAuth Redirect URL
In your Strava API settings (strava.com/settings/api), add your production URL to "Authorization Callback Domain".

## Troubleshooting

### App won't start
- Check logs in your hosting platform
- Verify all environment variables are set
- Ensure requirements.txt includes all dependencies

### Strava API not working
- Verify environment variables are set correctly
- Check if your Strava app has the correct callback URL
- Ensure your refresh token is still valid

### Slow performance
- Free tiers often have cold starts (first request is slow)
- Consider upgrading to paid tier or using a cron job to keep the app warm
